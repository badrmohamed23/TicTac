# 🎮 Tic-Tac-Toe (Python)

A simple **Tic-Tac-Toe game** written in Python where you play against the computer.  
The computer makes random moves while you play as **O** and the computer plays as **X**.

---

## 📌 Table of Contents

- [How to Play](#-how-to-play)


---

## 🚀 Features
- ✅ Playable **human vs computer** Tic-Tac-Toe  
- ✅ Computer starts first with **X** in the middle  
- ✅ Human makes moves by entering numbers **1–9** (grid positions)  
- ✅ Checks for **victory conditions** (rows, columns, diagonals)  
- ✅ Handles **invalid and occupied moves** gracefully  
- ✅ Declares the result: **You win, Computer wins, or Tie**
